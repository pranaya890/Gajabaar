## 2. What is the Shell?

The shell is a text-based interface used to interact with a computer.  
Instead of clicking through a graphical interface, we can type commands to:

- Run programs
- Navigate directories
- Read and modify files
- Search for information
- Connect commands together
- Automate repetitive tasks  
    Common shells include:
- Bash
- Zsh

## 3. Terminal vs Shell

**Terminal:** The program/window where we interact with the shell.  
**Shell:** The program that interprets our commands and executes programs.  
On Linux, a terminal will commonly start Bash or another shell.  
Check the current shell with:

```bash
echo $SHELL
```

## 4. Basic Commands

### `date`

Displays the current date and time.

```bash
date
```

### `echo`

Prints text or variable values.

```bash
echo hello
echo $PATH
```

### `pwd`

Prints the current working directory.

```bash
pwd
```

### `ls`

Lists files and directories.

```bash
ls
ls -l
ls -la
```

Useful options:

- `-l` → detailed/long listing
    
- `-a` → include hidden files
    

### `cd`

Changes the current directory.

```bash
cd /path/to/directory
cd ..
cd ~
cd /
```

Special paths:

- `.` → current directory
    
- `..` → parent directory
    
- `~` → home directory
    

## 5. Absolute vs Relative Paths

**Absolute path:** Starts from the root directory `/`.

```bash
cd /home/user/Documents
```

**Relative path:** Starts from the current directory.

```bash
cd Documents
```

The current directory matters when using relative paths.

## 6. Command Help

### `man`

Displays the manual page for a command.

```bash
man ls
man find
man grep
```

### `--help`

Many commands provide a shorter help page:

```bash
ls --help
grep --help
```

A useful habit is to check the documentation instead of blindly copying commands.

## 7. Command Arguments and Quoting

Commands can receive arguments:

```bash
echo hello
```

Arguments containing spaces need quoting or escaping:

```bash
echo "hello world"
echo 'hello world'
echo hello\ world
```

Different types of quotes have different behavior, so understanding shell quoting is important.

## 8. `$PATH`

`PATH` is an environment variable containing directories where the shell searches for executable programs.  
View it with:

```bash
echo $PATH
```

Example:

```text
/usr/local/bin:/usr/bin:/bin
```

When we type:

```bash
echo hello
```

the shell searches the directories in `$PATH` to find the `echo` executable.

### `which`

Shows which executable will be used:

```bash
which echo
```

We can also execute a program directly using its path:

```bash
/bin/echo hello
```

## 9. Useful File Commands

### `cat`

Displays file contents:

```bash
cat file.txt
```

### `sort`

Sorts lines:

```bash
sort file.txt
```

### `uniq`

Removes consecutive duplicate lines:

```bash
uniq file.txt
```

It is commonly combined with `sort`:

```bash
sort file.txt | uniq
```

### `head`

Shows the beginning of a file:

```bash
head file.txt
```

### `tail`

Shows the end of a file:

```bash
tail file.txt
```

## 10. `grep`

`grep` searches for lines matching a pattern.

```bash
grep "error" log.txt
```

Search recursively:

```bash
grep -r "TODO" .
```

`grep` can use regular expressions for more advanced searching.  
A useful alternative is `ripgrep` (`rg`), which is generally faster and more convenient for recursive searches.

## 11. `find`

`find` searches for files and directories based on conditions.  
Example:

```bash
find ~/Downloads -type f -name "*.zip"
```

Find files larger than 100 MB:

```bash
find ~ -type f -size +100M
```

Run another command on matching files:

```bash
find . -name "*.py" -exec grep -l "TODO" {} \;
```

Important options:

- `-type f` → regular files
    
- `-type d` → directories
    
- `-name` → filename pattern
    
- `-size` → file size
    
- `-mtime` → modification time
    
- `-exec` → execute a command on matches
    

## 12. `sed`

`sed` can perform automated text transformations.  
Example:

```bash
sed -i 's/old/new/g' file.txt
```

This replaces occurrences of `old` with `new`.  
Basic structure:

```text
s/pattern/replacement/g
```

- `s` → substitute
    
- `pattern` → text to find
    
- `replacement` → replacement text
    
- `g` → replace all matches on each line
    

## 13. `awk`

`awk` is useful for processing structured text and extracting columns.  
Example:

```bash
awk '{print $2}' file.txt
```

This prints the second whitespace-separated field from every line.  
For comma-separated data:

```bash
awk -F, '{print $2}' file.csv
```

`awk` can also filter records, perform calculations, and modify output.

## 14. Pipes

A pipe `|` sends the standard output of one command into the standard input of another command.  
Example:

```bash
cat file.txt | grep "error"
```

Another example:

```bash
sort file.txt | uniq -c
```

Pipes are one of the most powerful features of the shell because small programs can be combined to perform more complex tasks.

## 15. Redirection

### Output redirection

```bash
command > output.txt
```

Writes output to a file and overwrites the file.

### Append output

```bash
command >> output.txt
```

Adds output to the end of the file.

### Input redirection

```bash
command < input.txt
```

Uses a file as the command's standard input.

### `tee`

`tee` displays input while also saving it to a file:

```bash
command | tee output.txt
```

This is useful when we want to see output and keep a copy for later.

## 16. Standard Streams

Unix programs normally use three standard streams:

- `stdin` → standard input → file descriptor `0`
    
- `stdout` → standard output → file descriptor `1`
    
- `stderr` → standard error → file descriptor `2`  
    For example:
    

```bash
ls /nonexistent /tmp
```

The normal output and error output can be redirected separately.

## 17. Exit Status

Commands return an exit status.  
Usually:

- `0` → success
    
- Non-zero → error/failure  
    The previous command's exit status is stored in:
    

```bash
echo $?
```

Example:

```bash
ls
echo $?
```

## 18. `&&` and `||`

`&&` runs the next command only if the previous command succeeds:

```bash
command1 && command2
```

`||` runs the next command if the previous command fails:

```bash
command1 || command2
```

Example:

```bash
mkdir test && cd test
```

## 19. Command Substitution

`$()` allows the output of one command to be used inside another command.  
Example:

```bash
echo "Today is $(date)"
```

Another example:

```bash
filename="backup_$(date +%Y-%m-%d).txt"
```

This is very useful in shell scripts.

## 20. Variables

Variables can store values:

```bash
name="Pranaya"
echo "$name"
```

Environment variables can be accessed with `$`:

```bash
echo "$PATH"
echo "$HOME"
echo "$SHELL"
```

Quoting variables is generally a good habit:

```bash
echo "$name"
```

## 21. Conditionals

Bash supports conditional statements.  
Example:

```bash
if [ -f "file.txt" ]; then
    echo "File exists"
else
    echo "File does not exist"
fi
```

`[[ ]]` is also available in Bash and avoids some of the surprising behavior of the older `[ ]` form.

## 22. Loops

### `for` loop

```bash
for i in 1 2 3 4 5; do
    echo "$i"
done
```

Using command substitution:

```bash
for i in $(seq 1 10); do
    echo "$i"
done
```

### `while` loop

```bash
while command; do
    echo "Running"
done
```

Loops are useful for automating repetitive tasks.

## 23. Shell Scripts

Instead of typing a long sequence of commands every time, commands can be saved in a `.sh` file.  
Example:

```bash
#!/bin/bash

echo "Hello World"
```

The first line is called the **shebang**. It tells the system which interpreter should execute the script.  
Make it executable:

```bash
chmod +x script.sh
```

Run it:

```bash
./script.sh
```

## 24. `set -euo pipefail`

A common way to make Bash scripts safer is:

```bash
set -euo pipefail
```

Meaning:

- `-e` → exit when a command fails
    
- `-u` → treat undefined variables as errors
    
- `pipefail` → make a pipeline fail if one of its commands fails  
    These options help catch mistakes earlier in scripts.
    

## 25. Background Processes

Adding `&` runs a command in the background:

```bash
command &
```

This allows the shell to continue accepting commands while the process runs.  
The process ID can be stored using `$!`:

```bash
command &
PID=$!
```

## 26. Shell Debugging

Adding `-x` to Bash's `set` flags prints commands as they are executed:

```bash
set -x
```

This can help understand what a shell script is actually doing.

## 29. Key Takeaways

- The shell provides a powerful text-based way to control a computer.
    
- Learn navigation before trying complicated commands.
    
- `$PATH` determines where the shell searches for commands.
    
- Pipes allow commands to be combined.
    
- Redirection allows command input/output to be connected to files.
    
- `grep`, `find`, `sed`, and `awk` are powerful tools for searching and processing data.
    
- Bash is a programming language, not just a command launcher.
    
- Shell scripts can automate repetitive tasks.
    
- Exit statuses are important when writing reliable scripts.
    
- Reading `man` pages is an important skill.
    
- The goal is not to memorize commands blindly, but to understand how they can be combined to solve problems.
